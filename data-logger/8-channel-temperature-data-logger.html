8 Channel Temperature Data Logger

Order Code: RDL859

An 8-channel intelligent temperature data logger supporting PT100 RTD and J/K type thermocouple inputs, designed for industrial temperature monitoring with secure cloud connectivity over WiFi, 2G, 4G and LTE.

Key Features

  • 8-channel PT100 RTD sensor support (2-wire & 3-wire configurations)
  • 1x Relay (NO & C)
  • USB-device interface for configuration and monitoring
  • WiFi / 2G / 4G / LTE wireless communication
  • 8 GB inbuilt storage
  • Configurable data transferring protocol JSON / MQTT and FTP
  • Support secure communication SSL
  • Cloud platform compatibility (AWS, Azure, Google, Oracle, Things Board)
  • LED indicators for power, network, status and fault
  • Custom configurable polling intervals
  • 32-bit counter input configuration
  • Offline data logging to CSV during network failure
  • Auto-reconnection socket/server maintenance
