Cloud PLC - RPI - 0

Order Code: RDL895

The Programmable Cloud PLC offers Unmatched adaptability, reliable connectivity and customisable solution for your industry. Cloud PLC can be utilized as an edge gateway, Automation tool, data logger & edge processing node. Cloud PLC supporting wide range of industrial protocols like Modbus, MQTT, JSON, RESTful, TCP/UDP, SNMP, OPC which makes the solution integration easier than ever for IT / Automation engineers.

Cloud PLC 4.0 can used to build the custom industrial solutions for monitoring and controlling PLC and SCADA, HMI, VFD, Motors, servos, Valves, energy meters, actuators, relays, encoders, RFID and fingerprint readers, industrial sensors, and many more with below-mentioned benefits.

Key Features

  • 8x Isolated Analog Input Channel 0-10V, 0-24V, 4-20mA (16 Bit Resolution, 860SPS)
  • 2x Analog Output (AO) 0-10V
  • 2x 0-20mA Transmitter
  • 4x Isolated Digital Input 24V
  • 4x Isolated Digital Output / PWM 24V
  • 2x Relay (NO & C)
  • 1x Isolated RS485 for MODBUS RTU Communication
  • 1x Isolated RS232 Port
  • 1x USB-Device Interface for Configuring, Monitoring & Download
  • 1x Wi-Fi & Bluetooth Wireless Communication
  • Industrial Grade Design - Isolated & Protected IO & EMC / EMI Compliance
  • Configurable Data Transferring Protocol JSON / MQTT and FTP
  • Support Secure Communication SSL
  • Offline Data Storage - Supports Upto 16 GB External SD Card
  • Support most of the cloud platforms including Microsoft Azure & AWS
  • Power Supply - DC 9 - 36V
