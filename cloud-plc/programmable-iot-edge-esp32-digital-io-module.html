Cloud PLC - Digital IO Module

Order Code: RDL908

Cloud PLC Digital IO Modules can be used to build the custom solution for secure monitoring and controlling the IO. Field data collection over MODBUS RS485, Bluetooth, and USB make the monitoring and solution integration, easier than ever for IT engineers through open-source APIs.

Key Features

  • Open-source Hardware: ESP32 Dual-Core 32-bit Processor up to 240 MHz with 16 MB Flash
  • Compatible with most open-source programming platforms
  • Industrial protocols: MODBUS RTU, MODBUS TCP, JSON, MQTT, FTP
  • Support Secure Communication SSL
  • Industrial Grade Design - Isolated & Protected IO & EMC / EMI Compliance
  • Support most of the cloud platforms including Microsoft Azure & AWS
  • OTA Firmware Upgrade Capability
  • WiFi, Bluetooth & Modbus RTU Communication Support
  • 4x Isolated & Protected 24V Digital Inputs
  • 4x Isolated & Protected 7A Relay Outputs
