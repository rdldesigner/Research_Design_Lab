USB To RS485 Converter Module

Order Code: RDL/RSU/14/001/V1.0

Fully automatic plug-and-play USB module that connects to your PC via the Universal Serial Bus port and provides robust bidirectional USB to RS-485 protocol conversion with automatic flow control. Self-powered directly from USB, it lets you connect industrial RS485 devices such as PLCs, HMIs and sensors directly to a computer.

Key Features

  • Self-powered from USB
  • USB-RS485 interface with USB A/USB B connectors
  • EIA/TIA-485 communication with low power requirements
  • Thermal shutdown circuit prevents output shorting
  • Supports 32 slaves on RS485 Bus
  • UART support for 7-8 data bits, 1-2 stop bits, various parity options
  • Fully integrated USB termination resistors
  • 1024 bit EEPROM for device descriptors
  • Data rates: 300 baud to 5 Mbaud
  • FIFO receive/transmit buffers
  • Pre-programmed with unique USB serial number
  • Integrated power-on-reset circuit
  • USB 2.0 Full Speed compatible
  • FTDI VCP and D2XX drivers supported
  • TX/RX traffic indication via LEDs
  • Operating temperature: -40°C to 85°C
  • Compatible with PLC, HMI, surveillance cameras, video devices and fingerprint systems
