Digital Dimmer Module

Order Code: RDL/LDC/13/001/V1.0

The Digital Dimmer Module uses a BTA12-600B Triac for AC switching applications including static relays, heating regulation, and induction motor starting circuits. It supports phase control operations in light dimmers and appliance motor speed controllers, offering 0–100% dimming with 16 discrete levels controlled via any microcontroller digital output.

Key Features

  • Dimming method: Phase dimming
  • On/Off and dimming control
  • Circuit enabled with snubber
  • Auto zero cross detection
  • Accurate firing angle control and smooth dimming
  • Operating Voltage: 12V/24V DC
  • Isolated power section from input
  • 0-100% dimming
  • Load Capacity: 6 Amp AC (Up to 1500 Watt)
  • Works from any microcontroller input
  • Control up to 250V
