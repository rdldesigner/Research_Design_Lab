Programmable IoT Edge ESP32 Analog IO Module

Order Code: RDL865

* Refer to the Order Information Table below for the full feature comparison.

An open-source Hardware ESP32 dual-core 32-bit module running up to 240 MHz with 16 MB flash, built for custom programming on most open-source platforms. It supports multiple industrial protocols including MODBUS RTU, MODBUS TCP, JSON, MQTT, and FTP with secure SSL communication. The module offers isolated and protected I/O with EMC/EMI compliance, cloud connectivity to Microsoft Azure, AWS, Google Cloud, Firebase and ThingsBoard, and supports OTA firmware upgrades.

Key Features

  • Open-source Hardware ESP32 dual-core 32-bit, up to 240 MHz, 16 MB Flash
  • Supports most open-source platforms for custom programming
  • Industrial protocols: MODBUS RTU, MODBUS TCP, JSON, MQTT, FTP
  • Secure communication with SSL
  • Isolated & protected I/O with EMC/EMI compliance
  • Cloud connectivity: Microsoft Azure, AWS, Google Cloud, Firebase, ThingsBoard
  • OTA firmware upgrade supported
  • Communication: USB, WiFi, Bluetooth, and Modbus RTU

Internal Architecture

Internal block diagram showing the ESP32-WROOM-32 core, isolated RS485, analog input (16-bit ΔΣ ADC), USB-to-serial, relay outputs, digital inputs and isolated power supply.

Hardware Overview

ESP32 dual-core 32-bit LX6 microprocessor, ADC, opto-isolated relays, RS485 isolation, TTL to RS485 IC, FTDI configuration chip and DC-DC isolated power supply.
