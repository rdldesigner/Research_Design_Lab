USB 4 Channel Relay Board-FT245RL

Order Code: RDL/4RB/14/001/V4.0

A relay control module featuring four SPDT relays with USB connectivity. Suitable for home automation, hobby projects, and industrial automation, with manual or automatic timer-based operation capabilities.

Key Features

  • Completely opto-isolated relay module
  • Four SPDT relays (7A @ 250V rating)
  • Four digital I/O pins at 5V
  • FT245RL USB chipset with 1Mbyte/second data transfer
  • LED indicators for relay and power status
  • 70-micron PCB with quality connectors
  • Selectable power supply: 5V/12V/24V
  • Operating temperature: -40°C to 85°C
  • USB 2.0 Full Speed compatible
  • .NET, Java, and Python SDK support
