4-20mA Current Loop Transmitter XTR116U with Analog Input

Order Code: RDL707

This device functions as a precision current output converter designed to transmit analog signals across standard industrial current loops. It offers accurate current scaling and output current limit capabilities.

Key Features

  • Low quiescent current at 200µA
  • VREF sensor excitation: 4.096V
  • Span error: 0.05%
  • Nonlinearity error: 0.003%
  • Supply range: 7.5V to 36V
  • SO-8 Package format
  • I2C Interface compatibility

Analog 4-20mA Transmitter - Wiring Diagram

Analog 0-5V input is converted by the XTR116U to a 0-20mA/4-20mA current loop output. Board connections: GND, Analog Input (0-5V) and 5V on the input side, with 4-20mA output looped through a 12/24V supply.
