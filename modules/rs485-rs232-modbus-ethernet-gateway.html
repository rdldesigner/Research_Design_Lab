Modbus TCP Gateway

Order Code: RDL799

The gateway enables bidirectional communication between Modbus RTU and Modbus TCP networks. It retrieves data from various Modbus slaves — including energy meters, sensors, industrial PLCs, and variable frequency drives — via RTU protocol and transmits to TCP scanner devices. A configuration manager simplifies device setup.

Key Features

  • Supports Modbus RTU/ASCII/TCP master/client modes
  • Serial port with 2 kV isolation protection
  • Ethernet 10/100 Mbps connectivity
  • Functions as RTU-to-TCP converter and Ethernet/WiFi gateway
  • Static IP or DHCP support
  • RS232 to Ethernet/WiFi gateway capability
  • Open data communication support
  • Industrial design: -40 to 75°C operating range
  • Power supply: 12V-24V input
