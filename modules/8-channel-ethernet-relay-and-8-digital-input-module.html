8 Channel Ethernet Relay and 8 Digital Input Module

Order Code: RDL912

This module enables remote control of electrical devices via Ethernet with an integrated web server for setup. It supports multiple protocols including MODBUS TCP, TCP/IP, and MQTT. The device operates in both remote control and standalone modes, featuring a built-in real-time clock for scheduled operations without a computer connection. Suitable for network watchdog systems, irrigation, industrial automation, home/hotel automation, and IoT applications. Compatible with Node-RED, Home Assistant, Domoticz, and OpenHAB.

Key Features

  • 8x Relay 5 Amps 250VAC (NO & C)
  • Isolated Digital Input 24V
  • 1x Isolated Ethernet 10/100Mbps MODBUS TCP Communication
  • 1x USB-Device Interface for Configuring, Monitoring & Download
  • Industrial Grade Design - Isolated & Protected IO & EMC/EMI Compliance
  • Protocol MQTT, TCP/IP & Modbus TCP
  • 16 GB SD Card Storage for Logs
  • Support for cloud platforms including Microsoft Azure & AWS
  • Real Time Clock - RTC DS3231, Accuracy: +/- 3.5ppm From -40 to +85°C
  • Power Supply - DC 9-36V
  • Controller/Processor: Xtensa® 32-Bit LX7 Dual Core, 32 Bit, Up to 240MHz
  • 16 MB Flash Memory
  • Unique MAC Address LED Power Indication
  • Remote control with integrated web server for setup
  • Works in Remote control and Standalone mode

  • Robotics

Block Diagram

The controller manages 8 isolated relay outputs, 8 isolated digital inputs, Ethernet, USB, SD card storage and an onboard RTC, all protected by isolation and surge/noise filtering stages.

Cascading Multiple Relay Modules

Multiple RDL912 modules can be connected over a network switch and accessed remotely via the network using the remote control application software.

Home / Hotel Automation

The 8 relay channels can control lights, fans, door locks and TVs, with status and control accessible remotely over the internet from mobile or desktop apps.
