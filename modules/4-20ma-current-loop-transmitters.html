4-20mA Current Loop Transmitter XTR116U

Order Code: RDL625

The XTR116 module functions as precision current output converters designed to transmit analog 4-to-20mA signals over an industry standard current loop. It delivers accurate current scaling and output limiting capabilities with an I2C serial bus interface for bidirectional communication.

Key Features

  • Low Quiescent Current: 200µA
  • 5V regulator for external circuits
  • VREF for sensor excitation: 4.096V
  • Low span error: 0.05%
  • Low nonlinearity error: 0.003%
  • Wide loop supply range: 7.5V to 36V
  • SO-8 Package
  • I2C Interface
