8 Channel Relay Module - FT245RL

Order Code: RDL897

USB-controlled relay module featuring 8 SPDT relays rated at 7A each, enabling control of devices up to 230V/120V. Built around the FT245RL chipset with optical isolation and ESD protection, it is suitable for home automation, hobby projects, and industrial automation applications.

Key Features

  • 8 SPDT Relay Channels (7A 250V / 12A 120V / 10A 125VAC / 10A 28VDC)
  • LED indication for relay & Power supply
  • Raspberry Pi and Beaglebone Compatible
  • High Quality PCB FR4 Grade with FPT Certified
  • USB Connector: Type B
  • Chipset: FT245RL
  • FT245RL Optical isolation and ESD protection against communication noises
  • Virtual Com Port: Serial USB Communication
  • 8 Relay LED ON / OFF and Power Status indication
  • PCB Parameters: FR4 / 1.5mm / Double Layers / HAL
  • Mounting: Din Rail / Wall Mount
  • Extra PCB openings for better voltage isolation
  • Doubled high current tracks
  • Operating temperature range: From -30°C to +80°C
  • Size (LxHxW): 110mm x 72.5mm x 110mm
  • Supporting .Net, Python and Lab View Applications
  • Fully integrated USB termination resistors
  • Device supplied pre-programmed with unique USB serial number
  • USB 2.0 Full Speed compatible
  • Fully integrated 1024 bit EEPROM storing, device descriptors and FIFO I/O configuration
  • Power supply requirements (Selectable during purchase):
    • 5V DC / consumption - 500mA
    • 12V DC / consumption - 600mA
    • 24V DC / consumption - 400mA

  • Home automation
  • Process automation
  • Vending machines

  • Robotics

  • Remote monitoring

  • Aquarium control

Block Diagram

USB port connects through ESD protection and the FT245RL chip to the opto-isolation and relay driver stage, which drives all 8 relay channels.

Multi-Board Connection via USB Hub

Multiple relay modules can be connected to a single PC through a USB hub for controlling several sets of loads independently.

Software Support

The module can be controlled from a PC using .NET, Python, Java or LabVIEW applications via the FTDI driver.

I/O Connections

Raspberry Pi

Connect the relay module to a Raspberry Pi via USB to control all 8 relay channels and switch connected loads.

PC Wiring

Connect the module to a PC via USB and wire each relay's NO/C/NC terminals to the loads to be switched, such as lamps, motors and fans.
