Analog to 4-20mA Current Loop Transmitter

Order Code: RDL900

* Refer to the Order Information Table below for the full variant comparison.

An industrial-grade device designed to control the valve, VFD, test systems and sensor output conversion, with accurate current scaling and output current limit functions.

Key Features

  • ESD Protected
  • EMC/EMI compliance enabled design
  • Loop power-driven (no additional supply required)
  • Rugged, compact industrial adapter
  • 2-wire, 4-20mA current loop configuration
  • Supports 0-5V, 0-10V, and PWM analog inputs
  • Texas Instruments XTR116U chip
  • Low quiescent current: 200µA
  • 5V regulator for external circuits
  • VREF for sensor excitation: 4.096V
  • Low span error: 0.05%
  • Low nonlinearity: 0.003%
  • Wide loop supply range: 7.5V to 36V
  • RoHS-compliant SOIC package

IEC 61000-4-5 (lightning) see IPPM below

  • ESD immunity acc. IEC 61000-4-2
  • ±8 kV contact discharge
  • ±15 kV air discharge
  • ESD capability according to AEC-Q101

Applications

  • Smart transmitters
  • Industrial process control
  • Test systems
  • HART modem compatibility
  • Current amplification
  • Voltage-to-current conversion

Application Wiring Diagrams

Internal ESD-protected signal path (8KV contact / 15KV air protection, noise filter & over-voltage protection, Texas Instrument SOIC XTR116U), application wiring for a simple 4-20mA transmitter tester (RDL900), and 4-20mA transmission using the PWM technique (RDL900A).

Isolated PWM controlled 4-20mA transmitter with a PLC/IO module (RDL900B), and water/fuel level 4-20mA conversion using a VFD/valve controller and analog sensor module (RDL900).

4-20mA transmission using RPI (RDL900), and isolated PWM controlled 4-20mA transmitter with RPI (RDL900B).
