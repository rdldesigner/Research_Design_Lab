4 Channel 4-20mA Current Loop Receiver

Order Code: RDL769

This device enables connection of industrial sensors with 4-20mA output ranges. It provides high resolution with precision loop current measuring and works with pressure sensors, temperature sensors, humidity sensors, distance sensors, and flow meters commonly deployed in industrial settings.

Key Features

  • 4 channels for 4-20mA loop current reception
  • Low power consumption at 150µA
  • I2C interface communication
  • 5V supply voltage
  • 860 samples per second sampling rate
  • Noise rejection circuitry on all channels
  • Compatible with PLCs, Raspberry Pi, Arduino, ESP32, Particle, and standard control boards

Connection Diagram

Jumper closed to 5V position — onboard 5V is used to power the connected 4-20mA sensors.

Jumper closed to GND position — an external power supply is used for the connected 4-20mA sensors.

4-20mA Receiver Module on I2C Bus

Multiple 4-20mA receiver modules can be connected on a shared I2C bus (SCL/SDA), each configured with a different address (00, 01, 10) via onboard address-set jumpers, allowing up to 4 modules and 16 sensors on a single bus.
