Serial RS485 to Ethernet / WiFi Gateway

Order Code: RDL849

The gateway facilitates two-way communication between a serial terminal host and a TCP network. It includes a configuration manager for simplified device setup and uses an open data method to transfer information between serial hosts and TCP devices.

Key Features

  • RS485 connections with Ethernet/WiFi capability
  • Supports MODBUS RTU/ASCII/TCP protocols
  • 2 kV serial port isolation
  • 10/100 Mbps Ethernet
  • Operating temperature: -40°C to 75°C
  • Power supply: 12V-24V input
  • Supports static IP and DHCP configurations
