16 Channel 4A Industrial SSR Module

Order Code: RDL816

This module functions as a semiconductor equivalent of the electromechanical relay for controlling electrical loads without moving parts. The device supports ON/OFF switching and 0-100% dimming control via controllers, switches, and PLC logic. Applications include light control, fan management, power sockets, and Triac-compatible LED dimming.

Key Features

  • 4A capacity, 16 channels
  • On/Off control capability
  • Snubber circuit integration
  • Operating voltage: 12V/24V DC
  • Isolated power section from the input
  • Load capacity: 4 Amp AC (up to 960 Watts)

Advantages

  • No moving parts unlike electromechanical relays
  • Complete electrical isolation between input/output
  • No contact bounce issues
  • Zero voltage turn-on and zero current turn-off eliminate noise
  • AC load switching at zero current eliminates arcing
  • LED light dimming capability
  • Long operational life with high switching speeds

Applications

  • Light control
  • Fan management
  • Power sockets
  • Triac-compatible LED dimming
  • Machine control and control panel applications
