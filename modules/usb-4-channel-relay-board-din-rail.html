USB 4 Channel Relay Board - DIN Rail

Order Code: RDL861

This relay board with 4 SPDT relays and digital IO controlled via USB protocol, Suitable for home automation applications, hobby projects, and industrial automation. The free software application allows controlling relays manually or automatic operation by creating timers for each channel and enabling repeat cycle. Relay module support Windows & Linux platform, .Net / JAVA / Python SDK available for developing custom application.

Key Features

  • Opto-isolated relay design (3700VRMS)
  • LED status indicators for relay and power supply
  • DIN Rail compatible mounting
  • 4 × SPDT Relay (7A 250V / 12A 120V rated)
  • 4 × Digital IO 5V
  • USB Control Chipset FT245RL
  • High-quality PCB (70 Micron) with screw connectors
  • Power supply options: 5V / 12V / 24V
  • Data transfer up to 1 Mbyte/second
  • Extended operating range: -40°C to 85°C
  • Integrated USB serial number
  • Free software included: manual control and automatic timer with repeat cycles
  • .NET / Java / Python SDK available for custom application development
