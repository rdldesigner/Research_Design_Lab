LiFi Nano V2

Order Code: RDL749

LiFi Nano v2 is an easy-to-use, plug-and-play evaluation platform for a wide array of visible light communication applications in consumer, wearables, industrial, medical and Internet of Things (IoT) markets. The system comprises two modules: a transmit module connecting to lighting LEDs and a receive module linking to host communication systems.

Features

  • Support baud rate 38400
  • 6-15 feet distance (expandable via higher LED wattage)
  • High-intensity LED light
  • Domestic ceiling/wall mounting with focused LED for communication
  • Plug-and-play with simple configuration

Applications

  • Indoor wireless open optical communication
  • Indoor navigation
  • Underwater visible light communication
  • Smart indoor blind assistive applications
  • Vehicle-to-vehicle communication
  • Monitor-based data transmission
  • Phishing attack prevention using one-time passwords
  • Supermarket navigation and location-based discounts
  • Smart LiFi-based car parking
  • Location-aware services
  • Visible light positioning for asset tracking
  • Mobile robot navigation
  • Integrated underwater optical/acoustic systems
  • Traffic information broadcasting via visible light
