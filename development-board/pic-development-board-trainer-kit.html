PIC Development Board Trainer Kit

Order Code: RDL740

Start Your Embedded System Design Journey Today..!

PIC essential development features a plug-and-play design that makes it easy for connections and helps Students, hobbyists, enthusiasts, and professionals to focus more on Program / application development. PIC Development Board Trainer kit equipped with on board IO's, communication interfaces & peripherals. It is really easy to design, experiment with, and test circuits without soldering. It's used in many educational institutions and R&D LAB across the world.

Features

  • Plug & Play Interface Connectivity
  • 16*2 LCD & OLED Display
  • Professional EMI/RFI Compliant PCB Layout Design
  • 8 bit 4 port IO
  • Modular Block design makes Easy access & quick Prototyping
  • On Board WiFi / Bluetooth Connectivity
  • FRC connectivity features minimize the connection Error
  • 3.3 to 5V Level Converter
  • High Quality Grade PCB with wooden Enclosure
  • Power Supply 3.3V and 5V
  • On board Programming
  • SD CARD Interface
  • 8 interfacing LED's
  • RTC & EEPROM Interface
  • 1 * 4 Menu keypad
  • DC Motor/ Stepper Motor Driver
  • 4* 4 Matrix Keypad
  • Relay, Buzzer
  • RS232, RS485, USB communication port
  • 1x Temperature Sensor
  • 7 Segment Multiplexed Display
  • 3x Analog Test POT

Note: Optional OLED & SDCARD modules are provided on this board, Hobbyists/developers can make use of this module with their previous knowledge or open-source community support and we do not have the support for the optional module.

MCU

  • Only 35 single-word instructions to learn
  • All single-cycle instructions except for program branches, which are two-cycle
  • Operating speed: DC – 20 MHz clock input, DC – 200 ns instruction cycle
  • Up to 8K x 14 words of Flash Program Memory, up to 368 x 8 bytes of Data Memory (RAM), up to 256 x 8 bytes of EEPROM Data Memory
  • Pinout compatible to other 28-pin or 40/44-pin PIC16CXXX and PIC16FXXX microcontrollers

Analog Features

  • 10-bit, up to 8-channel Analog-to-Digital Converter (A/D)

Peripheral Features

  • Timer0: 8-bit timer/counter with 8-bit prescaler
  • Timer1: 16-bit timer/counter with prescaler
  • Timer2: 8-bit timer/counter with 8-bit period register, prescaler and postscaler
  • Two Capture, Compare, PWM modules
  • Synchronous Serial Port (SSP) with SPI™ (Master mode) and I2C™ (Master/Slave)
  • Universal Synchronous Asynchronous Receiver Transmitter (USART/SCI) with 9-bit address detection
  • Parallel Slave Port (PSP) – 8 bits wide with external RD, WR and CS controls (40/44-pin only)

Scope of Learning Experiments

  • LED blinking
  • Elevator Interface
  • 8 bit LED Left shift, Right shift and counting operation
  • Buzzer, Relay interface
  • Keypad Interrupt Interface
  • RS485, RS232 serial communication
  • 16*2 LCD interface
  • PWM Interface
  • Matrix Keypad Interface
  • UART Operation
  • ADC interface
  • RTC DS1307 I2C protocol interface
  • Traffic Light Signal Interface
  • AT24C04 EEPROM I2C protocol interface
  • 8 bit DIP switch interface
  • RF/WiFi Communication
  • 7 Segment interface
  • SPI protocol interface
  • L298 Driver for DC Motor and Stepper motor interface
  • Temperature Sensor Interface

Supported IC

PIC16F74, PIC16F77, PIC16F747, PIC16F777, PIC16F871, PIC16F874, PIC16F877, PIC16F877A, PIC16F887, PIC18F452, PIC18F458, PIC18F4220, PIC18F4320, PIC18F4431, PIC18F4331, PIC18F4520, PIC18F4420, PIC18F4550, PIC18F4455, PIC18F4580, PIC18F4480, PIC18F4585, PIC18F4680, PIC18F4620, PIC18F45J10, PIC18F44J10, PIC18F43K20, PIC18F44K20, PIC18F46K20
