ARM Development Board LPC2148-Trainer Kit

Order Code: RDL743

Start Your Embedded System Design Journey Today..!

LPC2148 essential development features a plug and play design that makes it easy for connections and helps Students, hobbyists, enthusiasts, and professionals to focus more on Program/application development. LPC2148 Development Trainer Kit equipped with on board IO's, communication interfaces & peripherals. It is really easy to design, experiment with, and test circuits without soldering. It's used in many educational institutions and R&D LAB across the world.

Features

  • Plug & Play Interface Connectivity
  • On Board Power supply 3.3V, 5V, 12V, GND
  • Professional EMI/RFI Compliant PCB Layout Design
  • 8-pin DIP switches
  • Modular Block design makes Easy access & quick Prototyping
  • Onboard voltage level converter
  • FRC connectivity features minimize the connection Error
  • Board enabled with the header for stacking the WiFi module
  • High Quality Grade PCB with wooden Enclosure
  • Board enabled with the header for stacking the Arduino shields
  • On board Micro SD card
  • On board debugging JTAG Option
  • ON/OFF slide switch
  • USB onboard programming
  • External jumper nodes
  • 8 interfacing LED's
  • Reset button
  • 1 * 4 interfacing keys
  • Power plug-in DC Socket
  • 4 * 4 interfacing keypad matrix
  • Power supply indicator LED
  • Two channel RS232 port for communication
  • Test led for Tx, Rx
  • 3 ADC potentiometer input interface
  • 46 General purpose IO
  • 16X2 LCD, OLED interface
  • FT232RL USB communication
  • 7 Seg Multiplexed Display

Note: Optional OLED & SDCARD modules are provided on this board, Hobbyists/developers can make use of this module with their previous knowledge or open-source community support and we do not have the support for the optional module.
